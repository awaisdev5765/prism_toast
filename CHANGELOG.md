# Changelog

## 0.1.0

- Initial release.
- `PrismToast` — adaptive toasts: bottom-centered on compact windows,
  stacked top-right cards on medium+ windows.
- Four icon-led variants (`success`, `error`, `warning`, `info`) with
  Material 3 container colors.
- Auto-dismiss, early dismissal, optional action buttons, and stacking of
  multiple toasts via a single overlay host.
